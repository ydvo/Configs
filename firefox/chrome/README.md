#  Firefox Config
- userChrome and userContent files for minimalistic Firefox config
- Meant for use with Tridactyl
- Based on https://github.com/Dook97/firefox-qutebrowser-userchrome
- `userContent.css` recolours Tridactyl (midnight/shydactyl base) with the
  Leo palette from `~/Configs/theme/palette.md`, applied as `!important`
  CSS var overrides instead of a `:colourscheme` theme file - this avoids
  needing the native messenger / "allow file access" permission.
